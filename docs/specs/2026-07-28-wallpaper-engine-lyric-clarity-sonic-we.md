# Wallpaper Engine、歌词清晰度与音域回响·WE

日期：2026-07-28

## Wallpaper Engine

- 使用独立资源库界面管理本地 Wallpaper Engine 项目，支持搜索、导入项目、导入目录、刷新、隐藏与恢复、属性详情、打开项目位置和创意工坊详情。
- Video 项目可直接播放；原生 Scene 只允许通过 Wallpaper Engine 运行经过验证的 `.pkg` / `.pak`。
- Web 与 Application 项目永远不执行，只能显示安全预览。
- Scene 自动静音；任何补丁只写入 Mineradio 缓存副本，不修改原项目。
- 当前选择跨重启、切歌保留；只有恢复原背景、选择其他壁纸或启用冲突的“音域回响·WE”时改变。
- 壁纸交互默认关闭，只允许空白舞台转发事件。
- 后台或最小化时冻结；用户开启“直播后台保持”后才继续运行。
- 没有 Wallpaper Engine 时 Video 仍可用；Scene 显示明确不可用原因，不自动打开 Steam 或下载页面。

## 歌词清晰度

- 提供 `1× 标清`、`2× 高清`、`3× 超清`、`4× 极致` 四档，默认 `2× 高清`。
- 原词、卡拉 OK 高亮、可读性阴影、辉光、音译与翻译使用同一实际纹理倍率。
- 使用 GPU 最大纹理尺寸和纹理内存预算限制实际倍率。
- 不静默修改用户选中的档位；受限时显示“硬件限制”以及实际倍率。

## 音域回响预设

- 保留内置“音域回响”，新增独立的“音域回响·WE”，两张卡片并列且分别存档。
- “音域回响·WE”绑定用户本地选择的原生 Scene，不随安装包附带第三方工程。
- 绑定项目缺失、移动或 Wallpaper Engine 不可用时，提示原因并安全回退到内置“音域回响”，不得黑屏。
- WE Scene 替换主粒子/地形视觉，但保留歌词、翻译、音译、控制台、3D 歌单架和玻璃界面。
- 向 Scene 低频节流传递输入增益、音频强度、响应范围和峰值强度。
